CS50 IDE
========

CS50 IDE, the Cloud9-based environment formerly at ide.cs50.io, was retired in 2023 and is no longer available. ``ide.cs50.io`` now redirects to `cs50.dev <https://cs50.dev/>`_.

CS50's current development environment is **Visual Studio Code for CS50** at `cs50.dev <https://cs50.dev/>`_, built on GitHub Codespaces. See :doc:`/cs50.dev` for how it is configured and :doc:`/cs50/codespace` for the Docker image that runs inside it.
